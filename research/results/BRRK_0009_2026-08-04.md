# BRRK-MVP-0009-LABEL-FREE-BADSTATE — 2026-08-04

Preregistered before the successful run. The first CI attempt failed only because of an implementation import error; the raw forward filter was then implemented locally without changing the statistical specification or any preregistered parameter.

## Purpose

Remove semantic HMM state names from the trading gate. Raw HMM labels may switch freely. Each raw state's V1 daily-return mean, variance and effective sample size are estimated from training-only posterior weights with the same shrinkage as BRRK-0005. A natural break-even boundary of zero is used to estimate `P(mu_raw < 0)`. The current label-free bad-state probability is the strictly forward-filtered raw-state posterior weighted average of these probabilities.

Trading rule:

`final_scale = 1 - p_bad * (1 - raw_state_meta_scale)`

No semantic state name controls trading and no threshold is searched.

## Research interpretation

0007 showed that factor-count specification can produce nearly opposite semantic classifications. 0008 showed that forcing persistent semantic identity is harmful. 0009 shows that semantic labels can be removed entirely, but the natural probabilistic negative-mean gate is too conservative to preserve V1's upside alpha.

The useful output of 0009 is therefore not a new production strategy but a model-invariant risk diagnostic: `p_bad`. It should be exposed in shadow automation alongside the PCA3/4/5 model-specification range, while frozen 0006 remains the research target until a replacement passes preregistered validation.
