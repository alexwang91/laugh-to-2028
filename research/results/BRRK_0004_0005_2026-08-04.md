## BRRK-MVP-0004-HYBRID

Frozen V1 alpha with a zero-mean HMM covariance/tail overlay. The overlay scaled V1 down whenever simulated 20-day terminal CVaR95 or path CDaR95 exceeded 20%.

Result:
- materially lower MDD and CDaR than V1;
- materially lower CAGR;
- Calmar fell from 1.628 to 1.239;
- 32 of 45 decisions were scaled below 1.0, including many BTC_LEAD / MAJOR_ROTATION / ALT_EXPANSION states;
- mean scale 0.742, minimum 0.447.

Interpretation: absolute tail-volatility budgeting treats high-upside/high-volatility bull regimes as if they were purely undesirable risk. This loses too much upside alpha.

Status: **NOT PROMOTED**.

## BRRK-MVP-0005-V1-META

Frozen V1 alpha with a one-dimensional meta allocator. Instead of modelling asset returns, the model estimates the conditional daily return distribution of the frozen V1 strategy itself. The scalar exposure maximizes simulated 20-day expected log wealth subject to the same 20% terminal CVaR95 and path CDaR95 constraints.

Result:
- improved materially versus 0004: CAGR 38.45% vs 35.63%, MDD -26.97% vs -28.77%, Calmar 1.425 vs 1.239, CDaR95 23.20% vs 27.53%;
- risk-adjusted Calmar exceeds BTC Dynamic (1.425 vs 1.286), though CAGR remains lower (38.45% vs 42.79%);
- still materially below frozen V1 Calmar 1.628 and CAGR 61.25%;
- mean selected scale 0.607; 9/45 decisions selected zero exposure; only 1/45 selected full exposure.

The state-conditioned V1 daily return estimates at the last decision were:
- RISK_OFF: -0.06498% / day;
- BTC_LEAD: +0.24049% / day;
- MAJOR_ROTATION: +0.26385% / day;
- ALT_EXPANSION: +0.16440% / day.

This is useful evidence that the latent state model contains conditional information about the *strategy* even though it was a poor replacement alpha model.

However, 0005 still cuts exposure in non-risk-off bull states because its absolute tail-risk constraint binds there. That remains the main upside-capture leak.

Status: **NOT PROMOTED, BUT RETAIN AS THE BEST BRRK RISK-MODEL PROTOTYPE SO FAR**.

## Structural next experiment

Register a new experiment rather than tuning 0005.

Core rule: **default to frozen V1. Give the meta allocator permission to de-risk only to the extent that the forward-filtered posterior assigns probability to RISK_OFF.**

A parameter-free first mapping is:

`final_scale = 1 - P(RISK_OFF) * (1 - meta_scale)`

where `meta_scale` is the preregistered 0005 scalar.

Consequences:
- P(RISK_OFF)=0 -> frozen V1 runs at full exposure;
- P(RISK_OFF)=1 -> use the 0005 meta allocator;
- intermediate posterior -> continuous blend;
- no arbitrary state probability threshold is introduced;
- no V1 alpha parameter, risk budget, state count, PCA count, shrinkage strength, Student-t df, or refit interval is changed.

The purpose is to test whether the HMM provides useful downside timing without paying the large bull-regime opportunity cost observed in 0004/0005.
